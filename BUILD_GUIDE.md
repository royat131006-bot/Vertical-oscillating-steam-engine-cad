# Build Guide

This is a practical SolidWorks reconstruction workflow. The portfolio gives no dimensions, so first choose a consistent design envelope and record the units.

1. Model a base, upright support, shaft, flywheel, crank, connecting rod, cylinder, and piston rod as named parts. Use fully defined sketches and named center distances.
2. Fix the base in a new assembly. Attach the support rigidly. Mate the shaft concentrically, restraining axial travel while allowing rotation.
3. Couple the flywheel and crank to the shaft. Add a pivot for the cylinder and joints for the connecting rod. Drag the mechanism after each mate to find overconstraints early.
4. Drive one shaft revolution in Motion Study. Check the cylinder swing, rod travel, interference, and mate warnings. Save an animation and record the simulation settings.
5. Export a drawing, exploded view, and bill of materials. Verify that all referenced parts open on another computer.

A CAD motion study does not establish steam flow, torque, thermal behavior, or durability. Add physical calculations and tests before making performance claims.
